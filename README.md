# image-metadata-extractor
Extract EXIF metadata and GPS location from images using Python
# Image Metadata Extractor

Mali Python alat za ekstrakciju EXIF metapodataka iz slika, uključujući GPS lokaciju.

## Instalacija

pip install -r requirements.txt

## Pokretanje

python metadata_extractor.py

## Primer

Unesi putanju do slike: slika.jpg
[+] Metapodaci za: slika.jpg
Make                     : Apple
Model                    : iPhone 12
DateTimeOriginal         : 2024:07:20 14:30:00
GPS Latitude             : 44.8125
GPS Longitude            : 20.4612

[🌍] Google Maps link:
https://www.google.com/maps?q=44.8125,20.4612

## Napomena

Ovaj alat je napravljen za edukaciju i OSINT vežbe.
